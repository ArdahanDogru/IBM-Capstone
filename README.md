# SpaceX Falcon 9 First Stage Landing Prediction

Predictive models to forecast SpaceX Falcon 9 first stage landing success using historical launch data.

## Project Overview
Built and evaluated multiple classification models (Support Vector Machines, Decision Trees, Logistic Regression) to predict landing outcomes, achieving 85%+ accuracy across 90+ launch records.

## Key Components
- **Data Collection**: Web scraping with BeautifulSoup and SpaceX API
- **Data Processing**: SQL queries, exploratory data analysis with Pandas/NumPy
- **Feature Engineering**: Launch site characteristics, payload specifications, orbit types
- **Modeling**: SVM, Decision Trees, Logistic Regression with cross-validation
- **Visualization**: Interactive dashboards with Plotly Dash and Folium for geospatial analysis

## Technologies Used
Python, Pandas, NumPy, Scikit-learn, BeautifulSoup, SQL, Plotly, Folium

## Results
Identified key factors affecting landing success including launch site proximity, payload mass, and orbit type.
